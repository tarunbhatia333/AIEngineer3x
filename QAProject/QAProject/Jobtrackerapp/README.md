# Job Pathway

A lightweight React job application tracker with drag-and-drop stages, theme switching, search, export/import, reminders, and preview cards.

## Run locally

1. Install dependencies:

```bash
cd "d:\VS code projects\JobPathway"
npm install
```

2. Start the development preview:

```bash
npm run dev
```

3. Open the localhost URL printed by Vite.

## Features

- Columns: Job Saved, Applied, In Progress, Follow-up, Interview, Offer, Rejected
- Drag cards between columns
- Add, edit, delete job cards
- Theme switcher with four visual themes
- Search and sort by company or role
- Export/import board JSON
- Select a card to preview search links and details
- Auto follow-up reminders for stale Applied cards
